# Changelog

## 1.0.0

First release.

- **All Subscriptions** key with three styles: Rings (one ring per subscription, 5h or weekly), Grid (a dial per subscription with 5h and weekly rings) and Dial (an arc per subscription with 5h and weekly bands).
- **Subscription Detail** key: 5h and weekly rings, % left, and time to reset.
- Real provider logos for Claude, Codex, Antigravity, Gemini, Kimi, Grok, Qwen, Meta, Devin, DeepSeek, Cursor and Copilot.
- Settings built for OpenDeck's settings panel: Key, Subscriptions and Connection tabs.
- Read-only access to CLIProxyAPI's management API (v8, falling back to v0). Stops after one rejected password so it can't trigger CLIProxyAPI's lockout.
- Press a key to reload; optional auto-refresh. Stream Deck+ dial switches style or subscription.
